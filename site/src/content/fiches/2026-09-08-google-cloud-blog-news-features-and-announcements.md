## Résumé
Google Cloud annonce que les instances Cloud Run évoluent vers des runtimes de calcul dédiés et "singleton", pensés pour des charges de travail persistantes plutôt que pour de simples requêtes ponctuelles. L'argument principal est le rapport coût-efficacité de ces instances pour des usages de longue durée. Le cas d'usage phare mis en avant est celui des agents d'IA personnels, qui nécessitent un environnement d'exécution stable et continu. Il s'agit d'un court billet de blog (catégorie "Serverless") signé Ryan Pei, annoncé comme une lecture de 3 minutes.

## Points clés
- Cloud Run se positionne désormais sur des charges de travail longue durée, au-delà du modèle serverless traditionnel à la requête.
- Les instances sont qualifiées de "dédiées" et "singleton", c'est-à-dire une instance unique et persistante par usage.
- L'argument commercial mis en avant est le rapport coût-efficacité de cette approche.
- Le cas d'usage explicitement cité est celui des agents d'IA personnels ("personal AI agents").
- Contenu publié sur le Google Cloud Blog, catégorie "Serverless", par Ryan Pei.
