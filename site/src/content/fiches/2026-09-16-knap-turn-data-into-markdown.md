## Résumé
Knap est un outil de templating qui transforme des données structurées en Markdown. Il permet d'insérer des variables directement dans un template, d'appliquer des filtres pour transformer et formater les valeurs, et d'utiliser une logique conditionnelle ainsi que des boucles sur des tableaux. L'outil est accessible via une interface en ligne de commande (CLI) documentée et via une API destinée à l'intégration dans des applications tierces.

## Points clés
- Knap génère du Markdown à partir de templates alimentés par des données.
- Les variables peuvent être insérées directement dans le texte du template.
- Des filtres permettent de transformer et de formater les valeurs affichées.
- Une logique conditionnelle permet d'inclure du contenu selon des conditions, et de répéter des blocs sur des tableaux (boucles).
- L'outil est utilisable en CLI (avec un guide dédié) ou intégrable dans une application via une API.
- L'exemple fourni illustre la génération d'un tableau Markdown listant des acteurs et leurs rôles (tiré du film Matrix).

## Analyse approfondie
Ajoutez des variables directement dans le Markdown. Les filtres modifient les valeurs et le formatage.

Générez du Markdown à partir de templates Knap. Consultez le guide CLI pour connaître les options disponibles.

Ajoutez le templating Knap à votre application via l'API.

### Variables

Insérez des valeurs issues de vos données dans un template.

### Filtres

Transformez les valeurs et formatez le Markdown.

### Logique

Incluez du contenu de manière conditionnelle et répétez-le sur des tableaux.
