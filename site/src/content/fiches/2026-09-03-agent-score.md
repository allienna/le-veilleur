## Résumé
Mintlify met en avant "Agent Score", une manière de mesurer si une documentation est réellement lisible par des agents IA, et non plus seulement par des humains ou des crawlers classiques. La thèse centrale : les agents interagissent avec le contenu différemment, en tronquant l'information avant qu'elle n'atteigne le LLM, ce qui peut provoquer des échecs silencieux invisibles pour les équipes produit. Une documentation mal adaptée devient un risque de fiabilité à grande échelle, car une erreur peut être répliquée par des milliers d'agents, pipelines RAG et chatbots. La documentation est ainsi présentée comme le nouveau "code source" de tout produit IA qui s'appuie dessus.

## Points clés
- Un nombre croissant d'utilisateurs accèdent à la documentation via des agents plutôt que via une page statique classique.
- Les agents ne sont pas des crawlers web : ils élaguent le contenu avant qu'il n'atteigne leur LLM principal, ce qui pénalise les pages non conçues pour cette contrainte.
- Une documentation non "agent-ready" entraîne des échecs silencieux, sur des surfaces que personne ne surveille.
- Une seule erreur dans un exemple de code peut désormais générer des milliers de réponses erronées mais formulées avec assurance, via les agents, le RAG et les chatbots.
- La dette documentaire est requalifiée en problème de fiabilité de niveau production, et non plus en simple friction pour quelques lecteurs.
- Mintlify positionne des outils comme "Agent Score" et "Doc Detective" pour aider les équipes à combler cet écart.
