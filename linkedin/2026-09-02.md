Un dev qui livre 5 projets sans écrire le code lui-même. Une équipe où les agents signent 76% des pull requests. Le code n'est plus le goulot d'étranglement — la validation l'est.

Ce que je retiens de ma veille du jour : plus vos agents produisent, plus la « cécité aux anomalies » qui touche déjà les humains devient le vrai risque business. Pas un problème de puissance du modèle. Un problème de qui regarde, et avec quels outils.

Sans évals, sans contexte traçable, sans sandbox de validation dédiée : vous scalez la production de bugs, pas la production de valeur.

Qui chez vous a explicitement la responsabilité de voir ce que l'agent ne voit pas ?
