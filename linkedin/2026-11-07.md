6,3 milliards de dollars volés à Binance en 20 minutes. Un data center Google à Londres resté sans courant parce qu'un automate n'a pas démarré les générateurs. Deux histoires, aucun zero-day : juste une couche ennuyeuse que plus personne ne surveillait.

Un bug PHP classé « priorité basse » en 2024 devient une faille critique dès qu'un outil d'IA rend l'attaque moins chère. Un composant « réutilisable » censé simplifier le code finit noyé d'exceptions. Un design system un peu lent ralentit toutes les applications construites dessus, sans qu'aucune équipe cliente ne puisse le corriger elle-même.

Seul GitHub a choisi d'anticiper : refondre le stockage Git avant que les agents de code ne le fassent plier.

Et chez vous, quelle est la couche qu'on n'a pas touchée depuis 2024 ?
