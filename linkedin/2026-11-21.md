Écrire du code avec un agent est devenu trivial. Le relire sérieusement, ça reste un métier à part.

Sur le noyau Linux, 85 000 patchs atterrissent chaque année — d'où Sashiko, le reviewer agentique construit par Google. Mais même les evals censées remplacer l'A/B test cachent des pièges : chez Spotify, un calcul naïf sous-estimait de moitié le vrai lien entre eval et résultat réel. Et quand Stripe exige que tous les critères soient remplis, le taux de réussite des agents de code s'effondre de 78 % à 29 %.

Résultat : les harnais de code deviennent jetables, mais les politiques, les evals et la mémoire produit restent, elles, à construire soi-même.
